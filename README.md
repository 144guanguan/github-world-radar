# GitHub 世界雷达

一个持续运行、可追溯、跨领域的 GitHub 发现系统。它每天从公开证据中寻找正在出现、升温或发生重要变化的项目，并把结果沉淀为长期可浏览的知识资产，而不只是一份容易过期的热门榜单。

关注范围不限于软件开发，也包括科学研究、生命健康、气候能源、开放数据、教育、公共事务、金融、硬件、机器人、艺术、音乐、游戏、数字文化以及难以归类但具有认知价值的实验。

## 运行原则

- **跨领域**：避免 AI、编程框架或开发工具长期占满榜单。
- **看变化，不只看总量**：区分新出现、近期升温、成熟项目重新活跃和长期热门。
- **证据优先**：所有时效性结论记录 `as-of` 时间，并附仓库、Release、Commit、Issue、PR、论文或官网证据。
- **事实与推断分离**：无法取得的指标保持为空，不估算、不编造。
- **持续积累**：日报回答“今天发生了什么”，项目档案回答“它如何一路变化”。
- **幂等更新**：同一天重复运行更新同一批次，不制造重复报告。

## 自动更新流程

```text
检查固定目录与远程仓库
        ↓
同步 main（仅 fast-forward）
        ↓
跨领域检索与证据核验
        ↓
写入结构化运行记录
        ↓
重建日报、项目档案、索引与图表
        ↓
校验后提交并推送
        ↓
GitHub Pages 自动发布
```
